A one-sentence pitch for a ridiculous invention: a kettle with a daily boil
limit that sighs at 42 dB on boil #7, logs its own burnout risk, and goes on
strike until tomorrow.

Run it with:

```sh
python3 main.py
```

It writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
gated to exactly one sentence of 1–220 characters and verified byte-for-byte.
